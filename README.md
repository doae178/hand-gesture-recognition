🤖 Hand Gesture Recognition using MobileNetV2

This project is a real-time AI system for hand gesture recognition using:

MobileNetV2 (fine-tuned)

TensorFlow 2.20

Gradio for Web Interface

OpenCV for preprocessing

It supports 4 gestures:

✊ Fist

👌 OK

✋ Palm

✌️ Peace

🚀 Features

Real-time webcam detection

Web interface with Gradio

Start/Stop detection controls

ROI-based processing for faster inference

High accuracy (97–99%) using transfer learning

Clean modular code
